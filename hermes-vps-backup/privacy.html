Privacy notice

Updated 15 October 2026 · Contact: privacy@pryara.com

1. Operator and scope

Hermes VPS Backup is operated privately by the account holder who authorizes it, for recovery of that operator’s own Hermes Agent installation. This notice covers that backup utility and its information pages. It is separate from the Pryara EOI service and from the different tool named Pryara Backup described in Pryara’s general privacy notice.

There is no public signup service. Website visitors are not asked to authorize access to their Google accounts. Privacy questions about this utility can be sent to privacy@pryara.com with “Hermes VPS Backup” in the subject.

2. Information handled

Recovery copies can include application configuration, conversations, memory, skills, approved workspace files and credentials necessary to recover the operator’s installation. The utility encrypts this content locally with restic before uploading it to Google Drive.

The Google connection also processes authorization tokens and the file identifiers, names, sizes and timestamps needed to store, find, verify and restore the encrypted repository. Google can see the account identity and storage/transfer metadata; encryption of backup content does not hide that metadata.

3. Google permissions and purpose

The utility requests https://www.googleapis.com/auth/drive.file to create and manage files associated with this backup connection. It does not request unrestricted access to all Drive files, Gmail or Calendar. Access is used for encrypted backup storage, integrity checks, recovery and approved repository retention.

Google API data is not sold, used for advertising or used by this backup utility to train AI models. Its use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements where applicable.

4. Storage, providers and protection

Google Drive stores the encrypted repository. The operator’s server, hosted by Contabo, holds the local application state and performs backup/recovery operations. Google authorization credentials and the backup recovery password are stored in protected host configuration outside the Hermes agent’s accessible environment. The operator keeps an independent recovery-password copy.

Telegram is used for short private operational-status alerts. These alerts do not contain backup content, conversation text, recovery passwords or authorization tokens. This backup utility sends no backup content to an AI model provider.

Storage and communications providers process the metadata needed to operate their services under their own terms. Encrypted storage does not make the repository immutable: misuse or revocation of account access can affect availability.

5. Retention and deletion

Manual encrypted backups and recovery checks have passed. Automatic backup scheduling and retention are not yet active. The planned policy keeps seven daily and four weekly recovery points; periods can overlap.

Existing verified snapshots, protected recovery anchors and local recovery copies can remain until the operator deliberately reviews and removes them. This notice does not promise a maximum automatic deletion period while scheduled retention is not active. Deleting data from the live application does not immediately remove copies already held in backups.

Revoking Google authorization stops future authorized access; it does not itself delete existing files from Google Drive. Deleting a backup repository is a separate deliberate operation. Requests about retained data should be directed to the privacy contact.

6. Website visitors

These information pages contain no forms, analytics, advertising, third-party embeds or executable scripts and do not set application cookies. They use the site’s existing locally hosted stylesheet and fonts.

The site is hosted on GitHub Pages. GitHub may record technical information such as visitors’ IP addresses to deliver and secure the site, as described in the GitHub General Privacy Statement. Following an external link or sending an email uses the relevant provider’s service.

7. Contact and changes

For questions, access concerns or deletion requests relating to this utility, contact privacy@pryara.com. This mailbox is shared as a contact address; the utility remains personally operated and distinct from Pryara’s EOI service.

This notice will be updated when the utility’s data handling changes, including activation of automatic retention. Changes that require renewed consent will be presented before the corresponding new access or use.
